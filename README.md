📊 CodeOrbit Sales Dashboard — Excel Data Analytics Project

 📌 Project Overview

This project was completed as part of my Data Analytics Internship at CodeOrbit.

The goal of this project was to analyze sales data using **Microsoft Excel**, identify important business trends, calculate key performance indicators (KPIs), and create an interactive sales dashboard.

This project demonstrates how raw sales data can be transformed into meaningful business insights using data analysis, visualization, and dashboarding techniques.

---

🎯 Project Objectives

The main objectives of this project were to:

- Analyze overall sales performance
- Track monthly sales trends
- Compare sales across product categories
- Analyze regional sales performance
- Identify top-performing products
- Calculate key business KPIs
- Build an interactive Excel dashboard
- Generate meaningful business insights

 📊 Dashboard Analysis

1. Monthly Sales Trend

The monthly sales analysis helps identify:

- Sales growth and decline
- High-performing months
- Seasonal patterns
- Changes in sales performance over time

Highest Sales Month: October 2025

 2. Sales by Category

The category analysis compares sales performance across different product categories.

Top-Performing Category: Grocery & Staples

 3. Regional Sales Analysis

The regional analysis compares sales performance across different regions and helps identify high- and low-performing areas.

 4. Top 5 Products

The dashboard identifies the five products generating the highest sales.

This helps understand which products contribute significantly to overall revenue.

 5. Category Ranking

Product categories are ranked based on their sales performance, making it easier to compare category-level contribution.

---

 💡 Key Insights

The analysis provided the following insights:

- Grocery & Staples was the highest-performing category.
- October 2022 recorded the highest monthly sales.
- Total sales amounted to ₹236,629.
- A total of 1,348 units were sold across 600 orders.
- The average order value was approximately ₹394.38.
- Category, regional, and product-level analysis can help identify opportunities for improving sales performance.

Data

Categories
